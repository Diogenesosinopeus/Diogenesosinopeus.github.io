# RSA 公钥密码体制复习笔记

> 根据《专题2-RSA公钥密码体制简介V2》整理。重点抓住密钥生成、加解密公式、正确性证明和安全性来源。

## 1. RSA 的基本想法

RSA 是一种公钥密码体制：公开公钥供任何人加密，只有掌握私钥的人能够解密。其数学基础是模幂运算容易计算，而从两个大素数乘积恢复其因子（整数分解）在参数足够大时很困难。

- 公钥：$ (N,e) $
- 私钥：$ (N,d) $，实际实现还会安全保存素数 $ p,q $ 等辅助参数。
- 明文按块编码为整数 $ M $，要求每块满足 $ 0\le M<N $。
- 密文：$ C $。

## 2. 密钥生成

1. 随机选择两个不同的大素数 $ p,q $。
2. 计算模数：

$ N=pq $

3. 计算欧拉函数：

$ \varphi(N)=(p-1)(q-1) $

4. 选择公开指数 $ e $，满足：

$ 1<e<\varphi(N),\qquad \gcd(e,\varphi(N))=1 $

5. 用扩展 Euclid 算法求 $ e $ 在模 $ \varphi(N) $ 下的乘法逆元 $ d $：

$ ed\equiv1\pmod{\varphi(N)} $

等价地，存在整数 $ k $ 使 $ ed=1+k\varphi(N) $。

6. 公布 $ (N,e) $；保密 $ d,p,q,\varphi(N) $。其中 $ p,q $ 泄露会使攻击者容易计算 $ \varphi(N) $ 并求出私钥。

## 3. 加密与解密

### 加密

发送者把明文块 $ M $ 用公钥计算为：

$ C\equiv M^e\pmod N $

### 解密

接收者用私钥计算：

$ M'\equiv C^d\pmod N $

RSA 的正确性要求解密结果满足 $ M'=M $。实际计算使用模幂算法，每次乘法后取模，避免产生巨大的中间整数。

## 4. 为什么解密能还原明文

由密钥构造有：

$ ed=1+k\varphi(N) $

若 $ \gcd(M,N)=1 $，由 Euler 定理：

$ M^{\varphi(N)}\equiv1\pmod N $

所以：

$ C^d\equiv(M^e)^d=M^{ed}=M^{1+k\varphi(N)}\equiv M\pmod N $

还需覆盖 $ M $ 与 $ N $ 不互素的情况。分别模 $ p $、$ q $ 证明：以模 $ p $ 为例，若 $ p\mid M $，则 $ M^{ed}\equiv M\equiv0\pmod p $；若 $ p\nmid M $，由 Fermat 小定理以及 $ ed\equiv1\pmod{p-1} $，有 $ M^{ed}\equiv M\pmod p $。模 $ q $ 同理。由于 $ p,q $ 互素，中国剩余定理推出：

$ M^{ed}\equiv M\pmod{pq} $

即：

$ C^d\equiv M\pmod N $

> 记忆链：$ ed\equiv1\pmod{\varphi(N)} $；密文是明文的 $ e $ 次模幂；解密再做 $ d $ 次模幂；Euler 定理（并结合模 $ p,q $ 的论证）保证还原。

## 5. 课件中的小例子

课件取：

$ p=17,\quad q=11 $

于是：

$ N=17\times11=187,\qquad \varphi(N)=16\times10=160 $

选取：

$ e=7 $

求逆元：

$ 7\times23=161=160+1 $

所以：

$ d=23 $

公钥为 $ (187,7) $，私钥为 $ (187,23) $。若明文为 $ M=88 $，则：

$ C\equiv88^7\pmod{187}=11 $

解密：

$ 11^{23}\pmod{187}=88 $

这是用于演算的小数值示例，不能用于真实安全场景。

## 6. 小例子：明文较大时的分块

另一页课件设 $ p=5,q=7 $，得到 $ N=35 $。当消息整数大于 $ N $ 时，不能把整个消息直接作为一个明文块；课件提示应先编码并分块，使每块均小于 $ N $。真实系统还需要规范的填充编码，不能直接对裸消息做 RSA。

## 7. RSA 与数字签名

数字签名用于验证来源和完整性。课件用“先对文件求哈希，再由签名者私钥处理哈希值；验证者用公钥验证并与重新计算的哈希比较”来说明流程。

概念上：

- 签名者对消息摘要使用私钥生成签名。
- 验证者用对应公钥检查签名，并确认摘要与收到的消息一致。
- 加密主要关注保密性；签名主要关注来源认证、完整性和不可否认性。

> 实际签名要使用标准的 RSA 签名编码方案，例如带安全填充的方案。不能把“私钥直接做一次幂运算”当作安全的实际签名算法。

## 8. 安全性与常见攻击思路

课件列出的攻击方向包括：

- **分解模数攻击**：对 $ N=pq $ 做整数分解；得到 $ p,q $ 后即可计算 $ \varphi(N) $ 并求出 $ d $。
- **共模攻击**：多个用户错误地共用同一个模数 $ N $，可能利用公开指数与相关密文恢复消息。每个用户应正确生成独立密钥，系统也应采用安全填充。
- **低指数攻击**：公开指数过小且编码、填充使用不当时，可能从密文中恢复明文。单纯增大指数并不能代替安全填充。
- **时间等侧信道攻击**：运行时间、功耗或缓存行为可能泄露私钥信息，需要实现层面的防护。

课件提到密钥参数随计算能力提高而增大，并举出约 $ 2048 $ 位的模数作为当时常见的安全参数说明。实际系统应遵循当前标准和经过审查的密码库配置；课件参数属于教学背景，不能直接当作现行部署建议。

## 9. 模幂的快速计算

计算 $ a^n\bmod m $ 时，不要先算出巨大整数 $ a^n $。把指数写成二进制，反复平方并在每步取模。

若：

$ n=(b_kb_{k-1}\cdots b_0)_2 $

从高位到低位维护中间值 $ c $，初值为 $ c=1 $。每读入一位，先平方；若该位为 $ 1 $，再乘以底数：

$ c\leftarrow c^2\bmod m $

若当前位 $ b_i=1 $，再做：

$ c\leftarrow ca\bmod m $

读完所有位后，$ c=a^n\bmod m $。运算过程中始终只保存模 $ m $ 的余数。

## 10. 易错点

1. $ \gcd(e,\varphi(N))=1 $ 才能保证 $ e $ 存在模 $ \varphi(N) $ 的逆元。
2. 加密和解密的指数不可混淆：加密用 $ e $，解密用 $ d $。
3. 明文块必须满足 $ 0\le M<N $；大消息要编码、分块。
4. Euler 定理的直接使用需要 $ \gcd(M,N)=1 $。完整正确性还要通过模 $ p,q $ 和中国剩余定理覆盖所有明文块。
5. 数学上可逆不等于实际实现安全。裸 RSA、错误填充、弱随机数或侧信道都可能破坏安全性。

## 11. 复习顺序

1. 背熟密钥生成的依赖关系：$ p,q\to N,\varphi(N)\to e\to d $。
2. 能手算小例子，尤其是用扩展 Euclid 算法求 $ d $。
3. 能说明正确性证明中 Euler 定理、Fermat 小定理和中国剩余定理各自负责哪一步。
4. 熟练用平方乘法计算模幂。
5. 最后把加密、签名、安全攻击三类问题区分开。

## 12. 全篇符号含义表

### RSA 参数与消息

| 符号 | 含义 |
|---|---|
| $p,q$ | 两个不同的大素数，构造 RSA 模数；必须保密。 |
| $N$ | RSA 模数，定义为 $pq$；公钥和私钥都包含它。 |
| $\varphi(N)$ | Euler 函数值；当 $N=pq$ 且 $p,q$ 为不同素数时，等于 $ (p-1)(q-1) $。 |
| $e$ | 公开加密指数，满足 $\gcd(e,\varphi(N))=1$。 |
| $d$ | 私有解密指数，是 $e$ 模 $\varphi(N)$ 的乘法逆元。 |
| $k$ | 整数，使 $ed=1+k\varphi(N)$；用于表示逆元关系。 |
| $M$ | 明文整数块，要求 $0\le M<N$。 |
| $M'$ | 解密得到的明文结果；正确时 $M'=M$。 |
| $C$ | 密文整数，满足 $C\equiv M^e\pmod N$。 |
| $a$ | 模幂示例中的底数；在密钥生成部分有时也泛指明文。 |
| $n$ | 快速模幂算法中的指数；不是 RSA 模数 $N$。 |
| $m$ | 快速模幂算法中的正模数；与大写 RSA 模数 $N$ 分开理解。 |
| $b_i$ | 指数 $n$ 的二进制位，取值为 $0$ 或 $1$。 |
| $b_k\cdots b_0$ | 指数的二进制表示，从最高位到最低位。 |
| $c$ | 快速模幂算法保存的当前结果；在 RSA 主体中小写 $c$ 也可能代表密文。 |
| $i$ | 二进制位下标。 |
| $\gcd(x,y)$ | $x,y$ 的最大公因数；等于 $1$ 表示互素。 |
| $\varphi(m)$ | 正整数 $m$ 的 Euler 函数，即小于等于 $m$ 且与 $m$ 互素的正整数个数。 |

### 算法与关系记号

| 符号 | 含义 |
|---|---|
| $(N,e)$ | RSA 公钥。 |
| $(N,d)$ | RSA 私钥的简写；真实实现通常还保留 $p,q$ 等私有辅助参数。 |
| $\equiv\pmod N$ | 模 $N$ 同余；两个整数之差能被 $N$ 整除。 |
| $\bmod N$ | 对 $N$ 取余，通常把结果取为 $0,1,\ldots,N-1$ 中的数。 |
| $\mid,\nmid$ | 整除、不整除。 |
| $\to,\leftarrow$ | 算法流程中的映射、赋值或更新方向，依语句而定。 |
| $\times$ | 乘法。 |
| $\varnothing$ | 空集；本笔记主要作为一般数学符号解释。 |
| $\le,<,=,\ne$ | 小于等于、小于、等于、不等于。 |
| $\varphi$ | Euler 函数符号；注意它不是变量 $p$ 或 $q$。 |
| $\cdots$ | 省略中间连续项。 |

| 示例 | 参数含义与取值 |

| 示例一 | $p=17,q=11,N=187,\varphi(N)=160,e=7,d=23,M=88,C=11$。 |
| 示例二 | $p=5,q=7,N=35$；用于说明明文整数块必须小于模数。 |
| 位数说明 | $2048$ 是课件中的模数位数示例，不是 RSA 公式中的变量。 |
