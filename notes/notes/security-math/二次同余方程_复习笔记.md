# 二次同余方程复习笔记

> 根据本次补充的教材图片整理。公式统一使用单美元符号 `$...$`。本笔记从二次剩余出发，依次学习 Legendre 符号、二次互反律、Jacobi 符号及 Rabin 密码体制。

## 二次同余方程与二次剩余

设 $p>2$ 为素数，且 $p\nmid a$。若同余方程

$x^2\equiv a\pmod p$

有解，则称 $a$ 是模 $p$ 的二次剩余；否则称为二次非剩余。满足方程的 $x$ 称为 $a$ 的平方根。

### 二次方程化为平方根问题

对 $ax^2+bx+c\equiv0\pmod p$，若 $p\nmid a$，则 $2a$ 可逆。配方：

$(2ax+b)^2\equiv b^2-4ac\pmod p$

令 $y=2ax+b$，原方程等价于一个平方根方程 $y^2\equiv b^2-4ac\pmod p$。解出 $y$ 后，再用 $x\equiv(y-b)(2a)^{-1}\pmod p$ 还原。

### 模素数的平方根数

对非零二次剩余 $a$，模 $p$ 有两个不同平方根 $x$ 与 $-x$；非剩余无解。非零模 $p$ 的剩余类中恰有 $(p-1)/2$ 个二次剩余、$(p-1)/2$ 个二次非剩余。

理由：若 $x^2\equiv y^2\pmod p$，则 $(x-y)(x+y)\equiv0\pmod p$，由于 $p$ 是素数，$y\equiv x$ 或 $y\equiv-x$。非零平方根成对出现，且 $x$ 与 $-x$ 不同。

### Euler 判别法

对 $p\nmid a$：

- 若 $a$ 是模 $p$ 二次剩余，则 $a^{(p-1)/2}\equiv1\pmod p$；
- 若 $a$ 是二次非剩余，则 $a^{(p-1)/2}\equiv-1\pmod p$。

因此可以通过一次模幂判断二次剩余性。

## Legendre 符号

设 $p>2$ 为素数，定义

$(\frac ap)=\begin{cases}1,&a\text{ 是模 }p\text{ 的二次剩余且 }p\nmid a\\-1,&a\text{ 是模 }p\text{ 的二次非剩余}\\0,&p\mid a\end{cases}$

Legendre 符号的值只可能是 $-1,0,1$。它是“二次剩余性质”的记号，不是方程解本身。

### 基本性质

1. 若 $a\equiv b\pmod p$，则 $(\frac ap)=(\frac bp)$。
2. $(\frac{ab}p)=(\frac ap)(\frac bp)$，即对分子完全乘法。
3. Euler 判别法可写成 $(\frac ap)\equiv a^{(p-1)/2}\pmod p$，其中右侧模 $p$ 的值 $1,-1$ 分别对应符号 $1,-1$。
4. $(\frac1p)=1$；若 $p\nmid a$，则 $(\frac{a^2}p)=1$。
5. $(-1/p)=(-1)^{(p-1)/2}$，所以 $-1$ 为二次剩余当且仅当 $p\equiv1\pmod4$。
6. $(2/p)=(-1)^{(p^2-1)/8}$，所以 $2$ 为二次剩余当且仅当 $p\equiv\pm1\pmod8$。
7. 对任意整数 $k$，$(\frac{a+kp}p)=(\frac ap)$。

### Gauss 引理

设 $p$ 为奇素数且 $p\nmid a$。把 $a,2a,\ldots,\frac{p-1}{2}a$ 分别模 $p$ 化为绝对值较小的代表元。若其中为负的个数是 $n$，则

$(\frac ap)=(-1)^n$

该引理把 Legendre 符号计算转化为计数正负代表元。取 $a=2$ 可以推出上面的二次补充律 $(2/p)$。

### 二次互反律

若 $p,q$ 是不同奇素数，则

$(\frac pq)(\frac qp)=(-1)^{\frac{p-1}{2}\frac{q-1}{2}}$

等价的分情况表述：

- 若 $p\equiv1\pmod4$ 或 $q\equiv1\pmod4$，则 $(\frac pq)=(\frac qp)$；
- 若 $p\equiv q\equiv3\pmod4$，则 $(\frac pq)=-(\frac qp)$。

它允许交换分子与分母，把较大的数逐步换成较小的数，并配合模数约化、乘法性和 $(2/p)$ 计算。

### 计算示例

求 $(\frac{137}{227})$。由模数约化，$137\equiv-90\pmod{227}$；将 $90=2\cdot3^2\cdot5$，再用乘法性、二次互反律及补充律逐步化简。教材结论为 $-1$，因此 $137$ 是模 $227$ 的二次非剩余，方程 $x^2\equiv137\pmod{227}$ 无解。

## Jacobi 符号

设分母 $n>1$ 为奇数，标准素因数分解为 $n=\prod_{i=1}^s p_i^{\alpha_i}$。定义

$(\frac an)=\prod_{i=1}^s(\frac a{p_i})^{\alpha_i}$

其中每个右侧符号都是 Legendre 符号。Jacobi 符号仍取 $-1,0,1$。

### 性质与重要区别

- 若 $n$ 是素数，Jacobi 符号就是 Legendre 符号。
- 对分子完全乘法：$(\frac{ab}n)=(\frac an)(\frac bn)$；对互素奇分母也有相应乘法性。
- 若 $a\equiv b\pmod n$，则 $(\frac an)=(\frac bn)$。
- $(\frac{-1}n)=(-1)^{(n-1)/2}$，$(\frac2n)=(-1)^{(n^2-1)/8}$。
- 若 $m,n$ 是互素奇正整数，则 $(\frac mn)(\frac nm)=(-1)^{\frac{m-1}{2}\frac{n-1}{2}}$。
- 若 $(a,n)=1$ 且 $(\frac an)=-1$，则 $a$ 一定不是模 $n$ 的平方；但 $(\frac an)=1$ 在合数分母时不保证 $a$ 是平方剩余。

**关键提醒**：Jacobi 符号为 $1$ 不能据此断言平方根存在。例：教材指出某合数模数下的 Jacobi 符号为 $1$，但对应平方同余仍可能无解。只有素数分母时，符号 $1$ 才等价于非零二次剩余。

### 实用计算步骤

1. 先利用 $a$ 对 $n$ 的模数约化。
2. 用乘法性把分子拆成素因子或易算因子。
3. 用二次互反律交换分子、分母，注意符号因子。
4. 遇到 $-1$、$2$ 使用补充律。
5. 反复迭代，直到分子或分母化为容易计算的值。

## Rabin 密码体制

Rabin 体制的加密计算与求模合数平方根直接相关。

### 密钥生成

1. 选择两个不同的大素数 $p,q$，满足 $p\equiv q\equiv3\pmod4$。
2. 计算 $n=pq$。
3. 公钥为 $n$；私钥为 $p,q$。

### 加密

把消息编码成整数 $m$，满足 $0\le m<n$，计算

$c\equiv m^2\pmod n$

### 解密

解密即求 $x^2\equiv c\pmod n$ 的平方根。先分别模 $p,q$ 求根，再用 CRT 合并。因为 $p,q\equiv3\pmod4$，对与素数模数互素的平方剩余 $c$，模 $p$ 的根可写为 $\pm c^{(p+1)/4}$，模 $q$ 的根可写为 $\pm c^{(q+1)/4}$。两边各有正负两个选择，通过 CRT 通常得到模 $n$ 的四个根。

因此单独的密文可能对应多个明文。为确定正确明文，实际方案需在消息编码中加入冗余信息或结构标记。

### 因数分解与平方根

若攻击者能对同一 $c$ 找到两个不相同且不只是互为相反数的模 $n$ 平方根 $u,v$，则

$n\mid(u-v)(u+v)$

利用最大公因数 $\gcd(u-v,n)$ 或 $\gcd(u+v,n)$，通常可恢复 $p,q$。所以求模合数平方根与分解 $n$ 有紧密关系。

### 与 RSA 的区别

- RSA 加密使用模幂 $m^e\pmod n$，解密依赖指数逆元。
- Rabin 加密使用平方 $m^2\pmod n$，解密要选取多个平方根之一。
- Rabin 体制的解密歧义需要编码消除；教材讨论的是数论教学模型，不等于完整的实际安全协议。

## 本笔记解题思路

- 判断 $x^2\equiv a\pmod p$ 是否有解：计算 Legendre 符号或 Euler 判别幂。
- 解一般二次方程：先配方，变成平方根方程。
- 手算 Legendre 符号：模数约化、乘法性、二次互反律、补充律。
- 计算 Jacobi 符号：按定义分解奇数分母；记住符号为 $1$ 对合数分母不保证有根。
- 解模 $pq$ 的平方根：分别模 $p,q$ 求根，再用 CRT 组合多个符号选择。

|---|---|
| $p,q$ | 奇素数；Rabin 小节中是两个不同且均模 $4$ 余 $3$ 的素数。 |
| $n$ | 正奇数模数；Rabin 中通常为 $pq$。 |
| $a,b,c,d$ | 整数、方程系数、判别式或密文，含义按所在公式确定。 |
| $x,y$ | 同余方程未知数或平方根变量。 |
| $m$ | 明文整数；Jacobi 互反律语境中也可能表示奇数分子。 |
| $e$ | Rabin 体制段落外的符号按上下文；本笔记 RSA 对照中可指公开指数。 |
| $k$ | 整数倍数参数，如 $a+kp$；也可能是计数下标。 |
| $\alpha_i$ | 素因数 $p_i$ 在奇数分母分解中的指数。 |
| $p_i$ | 合数分母分解中的第 $i$ 个不同素因子。 |
| $s$ | 不同素因子的个数。 |
| $n$ | 在 $(\frac an)$ 中是奇分母；勿与素数变量 $p$ 混淆。 |
| $(\frac ap)$ | Legendre 符号；$p$ 必须为奇素数。 |
| $(\frac an)$ | Jacobi 符号；$n$ 为奇正整数，未必为素数。 |
| $\gcd(a,n)$ | 最大公因数；$1$ 表示互素。 |
| $\equiv\pmod n$ | 模 $n$ 同余。 |
| $\mid,\nmid$ | 整除、不整除。 |
| $\prod,\sum$ | 连乘、连加。 |

| $f'(x)$ | 多项式导数（在本部分根提升中出现）。 |

| $\mathbb Z$ | 全体整数。 |

| $\Rightarrow,\Leftrightarrow$ | 推出、当且仅当。 |
