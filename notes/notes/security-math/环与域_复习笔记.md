# 环、整环、域与理想：复习笔记

> 整理依据：新加入的三份课堂 PDF，以及教材照片中关于环、域、商环和多项式环的内容。课堂 PDF 与照片有重合处，下面按概念脉络合并；图片中超出 PDF 的多项式环内容也一并收录。数学表达式使用单美元符号。

## 一、先建立整体框架

环是在一个集合上同时研究加法和乘法的代数结构。它的加法必须构成 Abel 群，乘法满足结合律，并且乘法对加法满足分配律。进一步增加条件，就得到交换环、有单位元环、整环、除环和域。

子环是保留原环运算的较小环；理想则是对原环乘法“吸收”的特殊子环，因此可以用它构造商环。多项式环把系数所在的环扩展为多项式；在域上可用多项式除法、因式定理和 Euclid 算法研究多项式。

结构关系可以记作：域一定是整环；整环一定是交换且有单位元的环，但反向一般不成立。除环不要求乘法交换；若除环乘法交换，它就是域。

## 二、环的定义与基本性质

### 环

设 $R$ 是非空集合，定义加法 $+$ 和乘法 $\cdot$。若满足以下条件，就称 $R$ 为环：

1. $(R,+)$ 是 Abel 群：加法封闭、满足结合律、有加法单位元 $0$、每个元素有加法逆元 $-a$，且加法满足交换律。
2. 乘法满足结合律：对所有 $a,b,c\in R$，有 $(ab)c=a(bc)$。
3. 乘法对加法满足左右分配律：$a(b+c)=ab+ac$，$(a+b)c=ac+bc$。

环不一定要求乘法交换，也不一定要求存在乘法单位元。若乘法交换，则称交换环；若存在 $1_R$ 满足 $1_Ra=a1_R=a$，则称有单位元环。

### 环中的常用恒等式

在任意环中：

- $a\cdot 0=0\cdot a=0$。
- $a(-b)=(-a)b=-(ab)$。
- $n(a+b)=na+nb$，其中 $na$ 表示把 $a$ 相加 $n$ 次。
- $a^m a^n=a^{m+n}$，$(a^m)^n=a^{mn}$；乘法不交换时，须注意因子顺序。
- 在交换环中可以使用二项式定理：$(a+b)^n=\sum_{k=0}^{n}\binom{n}{k}a^k b^{n-k}$。

### 例子

- 整数环 $\mathbb Z$：普通加法和乘法构成有单位元交换环，单位元为 $1$。
- 有理数、实数、复数：分别记为 $\mathbb Q,\mathbb R,\mathbb C$，都是域。
- 模 $n$ 剩余类环 $\mathbb Z/n\mathbb Z$：元素是模 $n$ 的剩余类，运算按模 $n$ 进行。
- $n$ 阶矩阵环 $M_n(F)$：矩阵加法和乘法构成环；当 $n\ge 2$ 时矩阵乘法通常不交换。
- 多项式环 $R[x]$：系数来自 $R$ 的所有多项式，在多项式加法和乘法下构成环。

## 三、零因子、整环、可逆元、除环与域

### 零因子与无零因子环

若存在非零 $a,b\in R$ 满足 $ab=0$，则 $a,b$ 是零因子。非交换环中还需区分左零因子和右零因子。若非零元素相乘不可能得到零，则称环无零因子。

例：在 $\mathbb Z/12\mathbb Z$ 中，$[3][4]=[0]$，而 $[3]\ne[0]$、$[4]\ne[0]$，所以它有零因子。若 $p$ 是素数，则 $\mathbb Z/p\mathbb Z$ 无零因子。

### 可逆元

在有单位元环 $R$ 中，若存在 $b\in R$ 使得 $ab=ba=1$，则 $a$ 可逆，$b$ 是 $a$ 的乘法逆元，记作 $a^{-1}$。所有可逆元在乘法下构成群，常记为 $R^\times$ 或 $R^*$。

整数环中只有 $1$ 和 $-1$ 可逆；在 $\mathbb Q,\mathbb R,\mathbb C$ 中，每个非零元素都可逆。

### 整环

整环是有单位元、乘法交换且无零因子的环。因此，整环中的消去律成立：若 $a\ne0$ 且 $ab=ac$，则 $b=c$。

整数环 $\mathbb Z$ 是整环，但不是域，因为例如 $2$ 在整数环中没有乘法逆元。合数模数的剩余类环不是整环；素数模数的剩余类环是域。

### 除环与域

除环是至少有两个元素、有单位元，且每个非零元素都可逆的环；乘法不必交换。域是乘法交换的除环。

有限整环一定是域。理解方法：对非零 $a$，映射 $x\mapsto ax$ 在有限整环上是单射；有限集合上的单射也是满射，因此存在 $x$ 使 $ax=1$，非零元素都有逆元。

### 特征

环的特征是使 $n\cdot1_R=0$ 成立的最小正整数 $n$；若不存在这样的正整数，特征记为 $0$。这里 $n\cdot1_R$ 表示把乘法单位元 $1_R$ 加 $n$ 次。

整环的特征只能是 $0$ 或素数。整数环、实数域的特征为 $0$；$\mathbb Z/p\mathbb Z$ 的特征为 $p$。

若交换环的特征为素数 $p$，则有 Frobenius 公式：$(a+b)^p=a^p+b^p$。迭代可得 $(a+b)^{p^m}=a^{p^m}+b^{p^m}$。

## 四、子环与环同态

### 子环判定

$S$ 是 $R$ 的非空子集时，$S$ 为子环的常用判定是：对任意 $a,b\in S$，都有 $a-b\in S$ 且 $ab\in S$。该判定同时保证 $S$ 对加法、加法逆元和乘法封闭。

注意：不同教材有时要求子环必须含有与母环相同的乘法单位元，有时不要求。使用判定时要遵循题目或课程约定；本组课堂讲义的子环定义没有把“必须含母环单位元”列为独立条件。

### 环同态

映射 $f:R\to R'$ 若保持加法和乘法，即对所有 $a,b\in R$ 有 $f(a+b)=f(a)+f(b)$、$f(ab)=f(a)f(b)$，则称为环同态。若同时单射、满射，分别称单同态、满同态；双射同态称同构。

同态会保持零元和加法逆元：$f(0)=0$、$f(-a)=-f(a)$。若定义中要求同态保持单位元，还需 $f(1_R)=1_{R'}$；不同教材对此的约定可能不同。

同态的核为 $\ker f=\{a\in R\mid f(a)=0\}$，它是 $R$ 的理想。环同态基本定理给出 $R/\ker f\cong f(R)$。

## 五、理想与商环

### 理想

环 $R$ 的非空子集 $I$ 是理想，若满足：

1. 对任意 $a,b\in I$，$a-b\in I$。
2. 对任意 $a\in I$ 和 $r\in R$，$ra\in I$ 且 $ar\in I$。

第二条叫吸收性。交换环中左右吸收条件相同；非交换环中左右理想的定义可能不同。本笔记按讲义采用双边理想。

每个环都有零理想 $\{0\}$ 和单位理想 $R$。在 $\mathbb Z$ 中，$n\mathbb Z=\{nk\mid k\in\mathbb Z\}$ 是理想。

### 商环

若 $I$ 是 $R$ 的理想，商环是陪集集合 $R/I=\{a+I\mid a\in R\}$，运算定义为：

- $(a+I)+(b+I)=(a+b)+I$。
- $(a+I)(b+I)=ab+I$。

理想的吸收性保证乘法与陪集代表元的选择无关，因此运算定义良好。整数环的商环 $\mathbb Z/n\mathbb Z$ 就是熟悉的模 $n$ 剩余类环。

## 六、多项式环和多项式 Euclid 算法

### 多项式与次数

$R[x]$ 表示系数取自环 $R$ 的多项式集合。一般多项式写作 $f(x)=a_nx^n+\cdots+a_1x+a_0$。若 $a_n\ne0$，则次数为 $\deg f=n$，$a_n$ 是首项系数。

当 $R$ 是整环时，$R[x]$ 也是整环。若系数环有零因子，多项式环也可能有零因子。

### 因式定理与根的个数

在域 $F$ 上，$a\in F$ 是 $f(x)\in F[x]$ 的根，当且仅当 $(x-a)$ 整除 $f(x)$，即 $f(a)=0\iff (x-a)\mid f(x)$。这是因式定理。

若 $f(x)$ 是非零多项式且 $\deg f=n$，则它在域 $F$ 中至多有 $n$ 个不同的根。证明思路是：每找到一个根就能提出一个一次因子，次数随之下降一。

### 多项式除法

在域 $F$ 上，若 $g(x)\ne0$，则存在唯一的 $q(x),r(x)\in F[x]$，使
$f(x)=q(x)g(x)+r(x)$，且 $r(x)=0$ 或 $\deg r<\deg g$。

反复使用多项式除法可得多项式 Euclid 算法。最后一个非零余式（适当归一化首项系数后）是最大公因式，并可反向代入得到 Bézout 等式：存在 $s(x),t(x)$ 使 $s(x)f(x)+t(x)g(x)=(f(x),g(x))$。

## 七、有限域的构造

设 $F_p=\mathbb Z/p\mathbb Z$，其中 $p$ 是素数。在 $F_p[x]$ 中取一个 $n$ 次不可约多项式 $f(x)$，则商环 $F_p[x]/(f(x))$ 是域，元素可用次数小于 $n$ 的多项式表示，因此共有 $p^n$ 个元素，记作 $GF(p^n)$。

不可约的含义：多项式不能分解为两个次数都更低的非恒定多项式之积。注意“不可约”依赖系数所在的域，例如图片中展示 $x^2+1$ 在有理数系数下不可约，但在某些有限域上可能可约。

## 八、易混概念对照

| 概念 | 必要条件 | 非零元素一定可逆吗？ | 乘法必须交换吗？ |
|---|---|---:|---:|
| 环 | 加法 Abel 群、乘法结合、分配律 | 否 | 否 |
| 交换环 | 环且乘法交换 | 否 | 是 |
| 整环 | 有单位元的交换环且无零因子 | 否 | 是 |
| 除环 | 有单位元且每个非零元可逆 | 是 | 否 |
| 域 | 交换除环 | 是 | 是 |

易错点：

- 有单位元不等于每个非零元都可逆。
- 无零因子不能单独推出“是域”；有限性等额外条件可能需要。
- 子环未必与母环拥有相同单位元。
- 商环需要理想作模数；仅有子环通常不够。
- 多项式根的“至多次数个”结论要求多项式非零且系数在域上。
- 非交换环中，$ab$ 与 $ba$ 不一定相等，左逆与右逆也不能随意互换。

## 九、符号说明

| 符号 | 含义 |
|---|---|
| $R,S,D,I,F$ | 环、环的子集/子环、理想或域；具体由上下文确定 |
| $R'$ | 另一个环，常作同态的目标环 |
| $a,b,c,r$ | 环中的元素；$r$ 有时表示任意环元素 |
| $+$、$\cdot$ 或并写的 $ab$ | 环的加法、乘法 |
| $0$、$1_R$ | 环的加法单位元、乘法单位元；有时简写为 $1$ |
| $-a$、$a^{-1}$ | $a$ 的加法逆元、乘法逆元（仅在可逆时存在） |
| $a^n$、$na$ | $n$ 次乘方、把 $a$ 加 $n$ 次；含义不同 |
| $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ | 整数、有理数、实数、复数集合 |
| $\mathbb Z/n\mathbb Z$ | 模 $n$ 的剩余类环 |
| $[a]$ 或 $a+I$ | $a$ 模理想 $I$ 的等价类/陪集 |
| $M_n(F)$ | 系数（元素）取自 $F$ 的 $n$ 阶方阵环 |
| $R[x],F[x]$ | 系数取自 $R,F$ 的多项式环 |
| $f(x),g(x)$ | 多项式；通常 $f$ 为被除式、$g$ 为除式 |
| $q(x),r(x)$ | 多项式商、余式；与环元素 $r$ 区分上下文 |
| $\deg f$ | 非零多项式 $f$ 的次数 |
| $f(a)$ | 将多项式变量 $x$ 取为 $a$ 后的值 |
| $(x-a)\mid f(x)$ | 一次多项式 $x-a$ 整除 $f(x)$ |
| $R^*$ 或 $R^\times$ | 环中所有可逆元构成的乘法群 |
| $\operatorname{char}(R)$ | 环的特征 |
| $\ker f$ | 同态 $f$ 的核，即映到零元的元素集合 |

| $\subseteq,\in,\mid$ | 子集、属于、整除 |
| $\forall,\exists$ | 对所有、存在 |

| $\binom{n}{k}$ | 二项式系数 $n!/(k!(n-k)!)$ |

## 十、建议学习顺序

1. 先能逐条判断一个对象是否为环：检查加法群、乘法结合、分配律。
2. 再区分是否交换、是否有单位元、是否有零因子；据此识别整环、除环和域。
3. 用熟悉的 $\mathbb Z$、$\mathbb Z/n\mathbb Z$、矩阵环做反例，检验定义边界。
4. 学子环与理想时，先练习判定条件，再理解“理想让商环乘法良定义”的原因。
5. 最后学习多项式：代入求值、因式定理、多项式除法、Euclid 算法、不可约多项式与有限域构造。
