# 群论与公钥密码体制

> 根据新加入的群论讲义和 ElGamal 公钥密码体制讲义整理。群论部分包括二元运算、群、子群与陪集、正规子群与同态、循环群；密码部分包括 ElGamal 加密、Diffie–Hellman 密钥协商、签名及相关方案。公式统一使用单美元符号 `$...$`。

## 二元运算与群

### 二元运算

集合 $A$ 上的二元运算是映射 $A\times A\to A$。对任意 $x,y\in A$，运算结果唯一且仍属于 $A$。常见运算性质：

- 结合律：$(x*y)*z=x*(y*z)$。
- 交换律：$x*y=y*x$。
- 分配律：若有两种运算 $*$ 和 $\circ$，则 $x*(y\circ z)=(x*y)\circ(x*z)$。

例如，整数上的加法、乘法都是二元运算；自然数上的减法通常不封闭，因此不是自然数集上的二元运算。

### 群的公理与快速判定

非空集合 $G$ 配上二元运算 $*$ 构成群，需满足封闭、结合律、单位元存在、每个元素都有逆元。

有限集合上有一个常用判定：若运算封闭、满足结合律和消去律，则该有限代数系统是群。无限集合不能直接照搬这个有限判定结论。

群中单位元、逆元唯一；左右消去律成立；方程 $a*x=b$ 和 $y*a=b$ 分别有唯一解 $x=a^{-1}*b$、$y=b*a^{-1}$。还要记住 $(a*b)^{-1}=b^{-1}*a^{-1}$，逆元会反转乘积顺序。

### 有限群与模运算例子

- $(\mathbb Z_n,+_n)$ 是模 $n$ 加法群，单位元是 $0$，$a$ 的加法逆元是 $-a\pmod n$。
- $\mathbb Z_n^*=\{a\in\mathbb Z_n:\gcd(a,n)=1\}$ 在模 $n$ 乘法下构成群，单位元是 $1$。
- 若 $p$ 为素数，则 $\mathbb Z_p^*=\{1,2,\ldots,p-1\}$，乘法群的阶为 $p-1$。

## 子群、陪集与 Lagrange 定理

### 子群判定

非空子集 $H\subseteq G$ 是子群的充要条件是对任意 $a,b\in H$，有 $a*b^{-1}\in H$。该条件一次性确保单位元、逆元和封闭性都在 $H$ 中。

例：整数加法群的子群为 $n\mathbb Z=\{nk:k\in\mathbb Z\}$，其中 $n$ 为非负整数；非零情形通常取 $n>0$。

### 陪集与划分

给定子群 $H\le G$ 和 $a\in G$，左陪集为 $aH=\{a*h:h\in H\}$，右陪集为 $Ha=\{h*a:h\in H\}$。陪集不一定是子群，但每个陪集与 $H$ 的元素个数相同。任意两个左陪集要么相同，要么不相交，因此所有左陪集划分整个群 $G$。

陪集个数称为指数 $[G:H]$。若 $G$ 有限，则 Lagrange 定理给出 $|G|=|H|[G:H]$，所以 $|H|$ 整除 $|G|$。进一步，有限群中每个元素的阶都整除群的阶。

### 元素的阶

元素 $a$ 的阶是满足 $a^r=e$ 的最小正整数 $r$，记为 $\operatorname{ord}(a)$。由 $a$ 生成的子群为 $\langle a\rangle=\{a^k:k\in\mathbb Z\}$，其元素个数等于 $a$ 的阶。

## 正规子群、商群和同态

### 正规子群

子群 $H\le G$ 若对每个 $a\in G$ 都有 $aH=Ha$，则 $H$ 是正规子群，记作 $H\trianglelefteq G$。等价条件是对任意 $a\in G,h\in H$，$a*h*a^{-1}\in H$。交换群的所有子群都是正规子群。

### 商群

当 $H\trianglelefteq G$ 时，所有陪集组成商群 $G/H$，运算为 $(aH)*(bH)=(a*b)H$。正规性保证换用同一陪集里的其他代表元，结果仍是同一个陪集。

例：$n\mathbb Z$ 是整数加法群 $\mathbb Z$ 的正规子群，商群 $\mathbb Z/n\mathbb Z$ 与模 $n$ 加法剩余类对应。

### 群同态、象、核

映射 $h:G\to K$ 满足 $h(a*b)=h(a)\cdot h(b)$ 时称为群同态。若它双射，则为群同构。群同态保单位元、逆元和元素的幂。

- 象：$h(G)=\{h(a):a\in G\}$，是 $K$ 的子群。
- 核：$\ker(h)=\{a\in G:h(a)=e_K\}$，是 $G$ 的正规子群。
- $h$ 单射当且仅当 $\ker(h)=\{e_G\}$。

**群同态基本定理**：满同态 $h:G\to K$ 给出 $G/\ker(h)\cong K$。意思是把核中的元素压缩成单位元后，所得商群与同态的像同构。

## 循环群

### 定义、生成元与结构

若存在 $g\in G$ 使 $G=\langle g\rangle$，则 $G$ 是循环群，$g$ 是生成元。无限循环群与整数加法群 $\mathbb Z$ 同构；阶为 $n$ 的有限循环群与模 $n$ 加法群 $\mathbb Z_n$ 同构。

无限循环群恰有两个生成元 $g$ 与 $g^{-1}$。若有限循环群 $G=\langle g\rangle$ 的阶为 $n$，则 $g^k$ 是生成元当且仅当 $\gcd(k,n)=1$，所以生成元个数为 Euler 函数 $\varphi(n)$。

循环群的子群和商群仍是循环群。一个有限循环群的阶决定其同构类型：同阶有限循环群彼此同构。

### 离散对数

在循环群 $G=\langle g\rangle$ 中，给定 $g$ 和 $h$，寻找整数 $k$ 使 $g^k=h$，称为离散对数问题，$k$ 是 $h$ 关于生成元 $g$ 的离散对数。有限群中指数通常按 $g$ 的阶取模。

## ElGamal 公钥加密

### 密钥生成

选择大素数 $p$ 和模 $p$ 乘法群的生成元 $g$。选择私钥 $\alpha$，计算 $\beta\equiv g^\alpha\pmod p$。

- 公钥：$(p,g,\beta)$。
- 私钥：$\alpha$。

### 加密与解密

明文记为 $x$。每次加密都随机选择新的秘密数 $k$，并计算

$r\equiv g^k\pmod p,\qquad s\equiv x\beta^k\pmod p$。

密文是 $(r,s)$。接收方用私钥计算

$x\equiv s(r^\alpha)^{-1}\pmod p$。

正确性来自 $r^\alpha\equiv g^{k\alpha}\equiv\beta^k\pmod p$，所以 $s(r^\alpha)^{-1}\equiv x\pmod p$。

**实用提醒**：加密时的 $k$ 必须保密且每次重新随机生成；重用随机数会造成严重信息泄露。教材讲义用于说明原理，实际系统应采用经过标准化审查的密码协议和参数。

## Diffie–Hellman 密钥协商

公开选择循环群 $G$ 及生成元 $g$。Alice 选私密随机数 $a$ 并发送 $g^a$；Bob 选私密随机数 $b$ 并发送 $g^b$。双方分别计算

$(g^b)^a=g^{ab},\qquad (g^a)^b=g^{ab}$。

两方得到相同的共享秘密 $g^{ab}$，但旁观者只看到 $g,g^a,g^b$。安全性依赖于在所选群中求离散对数或计算 Diffie–Hellman 共享值的困难性。协议本身不验证对方身份，单独使用会受中间人攻击。

## ElGamal 数字签名

继续使用素数 $p$、生成元 $g$ 和私钥 $\alpha$，公钥为 $\beta\equiv g^\alpha\pmod p$。对消息整数 $m$，随机选择 $k$ 且要求 $\gcd(k,p-1)=1$，计算

$r\equiv g^k\pmod p,\qquad s\equiv (m-\alpha r)k^{-1}\pmod{p-1}$。

签名为 $(r,s)$。验证者检查

$\beta^r r^s\equiv g^m\pmod p$。

因为 $\beta^r r^s\equiv g^{\alpha r}g^{ks}=g^{\alpha r+ks}\equiv g^m\pmod p$。签名用的 $k$ 必须保密、不可重复；若随机数泄露或复用，私钥可能被恢复。实际签名还需对消息做安全哈希并采用标准编码。

## Schnorr 签名与 DSA 的联系

讲义还介绍 Schnorr 签名和 DSA：它们都使用有限群、私钥指数、公开群元素以及签名随机数。Schnorr 的典型记法如下：选素数 $p,q$ 且 $q\mid(p-1)$，选模 $p$ 下阶为 $q$ 的元素 $g$；私钥为 $\alpha\in\mathbb Z_q$，公钥为 $\beta\equiv g^\alpha\pmod p$。对消息 $m$ 随机选 $k\in\mathbb Z_q$，计算

$v\equiv g^k\pmod p,\qquad r=H(m\|v)\pmod q,\qquad s\equiv k-r\alpha\pmod q$。

验证者计算 $v'\equiv g^s\beta^r\pmod p$，并检查 $H(m\|v')=r$。其中 $H$ 是哈希函数，$m\|v$ 表示按方案规定编码后连接消息与承诺值。DSA 与 ElGamal 签名有代数结构上的联系，但参数、签名和验证公式有特定规定，不应直接把上述 ElGamal 公式替代为 DSA。

|---|---|
| $A,G,H,K$ | 集合或群；$G,K$ 常分别表示源群与目标群，$H$ 常表示子群 |
| $x,y,z,a,b,c$ | 群或集合中的元素；在密码部分也可能表示明文或私密指数，按所在小节解释 |
| $*$、$\cdot$ | 抽象群运算；$\cdot$ 也可表示普通乘法 |
| $e,e_G,e_K$ | 群的单位元；下标说明属于哪个群 |
| $a^{-1}$ | $a$ 在群运算下的逆元 |
| $a^k$ | 群中元素 $a$ 的 $k$ 次幂；$k$ 为整数 |
| $\operatorname{ord}(a)$ | 元素 $a$ 的阶 |
| $|G|$ | 群 $G$ 的阶，即元素个数 |
| $H\le G$、$H\trianglelefteq G$ | 子群关系、正规子群关系 |
| $aH,Ha,[G:H],G/H$ | 左陪集、右陪集、子群指数、商群 |
| $h:G\to K$ | 从群 $G$ 到群 $K$ 的映射 |
| $h(G),\ker(h)$ | 同态的象、同态的核 |
| $\cong$ | 群同构 |
| $\mathbb Z,\mathbb Z_n,\mathbb Z_p^*$ | 整数群、模 $n$ 剩余类加群、模素数 $p$ 非零元素乘法群 |
| $n\mathbb Z$ | 所有整数倍数 $nk$ 组成的加法子群 |
| $\langle g\rangle$ | 由生成元 $g$ 的整数次幂组成的循环群 |
| $\varphi(n)$ | Euler 函数，计数 $1$ 到 $n$ 中与 $n$ 互素的整数个数 |
| $p$ | ElGamal 中使用的大素数；另在抽象群例子中也可能表示其他素数 |
| $q$ | Schnorr 类签名中使用的素数阶，满足 $q\mid(p-1)$ |
| $g$ | 模 $p$ 乘法群或一般循环群中的生成元 |
| $\alpha$ | ElGamal 私钥指数 |
| $\beta$ | ElGamal 公钥元素，满足 $\beta\equiv g^\alpha\pmod p$ |
| $k$ | 加密或签名时每次随机产生的临时秘密数；不是长期私钥 |
| $x$ | ElGamal 明文 |
| $r,s$ | ElGamal 密文的两个分量；签名时也表示签名分量，需按上下文区分 |
| $m$ | 签名章节中的消息整数 |
| $v,v'$ | Schnorr 签名中的承诺值及验证者重建的承诺值 |
| $H$ | Schnorr 签名中的哈希函数；同一字母在群论段也可能表示子群，须按上下文区分 |
| $\|$ | 消息编码的连接符号，表示把两段输入按规定格式拼接 |
| $a,b$ | Diffie–Hellman 双方各自选择的私密指数 |
| $\mathbb Z_p^*$ | 模 $p$ 的非零剩余类乘法群 |
| $\mathbb Z_{p-1}^*$ | 模 $p-1$ 的可逆剩余类，用于选择可求逆的签名随机数 |
| $\gcd(u,v)$ | 整数 $u,v$ 的最大公因数 |
| $u\equiv v\pmod n$ | $u$ 与 $v$ 模 $n$ 同余，即 $n\mid(u-v)$ |
| $H(\cdot)$ | 密码哈希函数；其输入和输出格式由具体方案规定 |
| $\ker$ | 同态核的记号；不是密码函数 |

## 容易混淆的点

1. 群的运算符号只是抽象记号；不交换时，左右顺序不能互换。
2. 陪集是集合；只有正规子群的陪集才能按标准方式组成商群。
3. 群同态保运算；单有双射还不足以称为同构。
4. 模 $p$ 与模 $p-1$ 出现在不同计算中：ElGamal 加解密的乘法在模 $p$ 下，而签名随机数求逆和 $s$ 的计算在模 $p-1$ 下。
5. ElGamal 加密的随机数和签名的随机数是临时秘密，必须保护；它们不可与长期私钥混为一谈。
